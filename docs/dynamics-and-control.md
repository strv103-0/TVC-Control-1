# 동역학과 제어 구조

이 기체가 왜 그렇게 움직이고, 제어기를 왜 그렇게 짜야 하는지에 대한 정리.
Simulink 모델의 블록 배치는 여기 유도된 식의 모양을 그대로 따라간다.

전제 지식: 정역학, 재료역학, 미적분.

---

# 1부. 동역학

## 1-1. 정역학에서 바뀌는 것은 우변 하나뿐

```
정역학:   ΣF = 0          ΣM_G = 0
동역학:   ΣF = m·a_G      ΣM_G = I_G·α
```

절차는 정역학과 같다. 자유물체도를 그리고, 힘과 모멘트를 모두 적고, 합을 쓴다.
다만 우변이 0이 아니라 관성항이다. 정역학은 가속도가 0인 특수한 경우다.

## 1-2. 관성모멘트 — 재료역학의 `I`와 구분할 것

이름과 기호가 같아 혼동하기 쉽다.

| | 재료역학의 `I` | 동역학의 `I` |
|---|---|---|
| 정의 | `I = ∫y² dA` | `I = ∫r² dm` |
| 가중 대상 | **면적** | **질량** |
| 단위 | m⁴ | kg·m² |
| 의미 | 굽힘에 대한 저항 | 회전 가속에 대한 저항 |
| 평행축 정리 | `I = I_c + A·d²` | `I = I_G + m·d²` |

형태가 닮은 이유는 둘 다 "축에서 떨어진 거리의 **제곱**으로 가중한 합"이기 때문이다.
재료역학의 "면적을 축에서 멀리 보내면 굽힘에 강해진다"는 직관이,
동역학에서는 "질량을 축에서 멀리 보내면 돌리기 어려워진다"로 그대로 옮겨온다.

우리 기체는 가늘고 긴 막대에 가까우므로 CAD 완성 전에는 이 근사를 쓴다.

```
I_G ≈ (1/12) · m · L_body²
```

CAD가 완성되면 Fusion이 계산한 실제 관성텐서로 교체한다.

## 1-3. 기호 정의와 자유물체도

| 기호 | 의미 |
|---|---|
| `θ` | 연직 기준 동체 기울기 (pitch) |
| `δ` | **동체축 기준** 짐벌 편향각 |
| `L` | 짐벌 회전중심 ~ 무게중심 거리 (모멘트 팔) |
| `T`, `m`, `I` | 추력, 질량, pitch 관성모멘트 |

작용하는 것은 둘뿐이다.

1. **추력 `T`** — 동체 아래 짐벌점에서, 동체축에서 `δ`만큼 꺾인 방향
2. **중력 `mg`** — 무게중심에서, 항상 연직 아래

무게중심을 기준으로 모멘트를 잡으면 **중력은 모멘트를 만들지 못한다.**
작용점이 곧 기준점이라 팔 길이가 0이다. 회전을 만드는 것은 추력뿐이다.

추력에서 동체축에 수직인 성분만 모멘트를 만들고, 팔 길이는 `L`이다.

```
M_G = T · sin(δ) · L

I · θ̈ = T · L · sin(δ)        ... (1)
```

## 1-4. 선형화

`sin δ`를 `δ = 0` 근처에서 전개하면 `sin δ ≈ δ` (라디안).

```
δ = 12° = 0.2094 rad
sin(12°) = 0.2079        오차 0.7%
```

짐벌 가동범위 안에서 1% 미만 오차이므로, 선형 모델로 설계하고 최종 검증만 비선형으로 한다.

```
θ̈ = (T·L / I) · δ        ... (2)
```

## 1-5. 이 식이 프로젝트 전체를 설명한다

식 (2)에서 `δ = 0`이면 `θ̈ = 0`이다. **기울어진 각도가 그대로 유지된다.**

진자와 비교하면 차이가 분명하다.

```
진자:       θ̈ = -(g/l)·sin θ      ← -θ 항이 있음 (복원)
이 기체:    θ̈ = (T·L/I)·δ         ← θ 항이 아예 없음
```

진자는 `-θ` 항 때문에 스스로 돌아온다. 이 기체에는 그 항 자체가 없다.
자유비행 중 중력은 무게중심에 작용하므로 모멘트를 만들지 못하기 때문이다.

> 가만두면 넘어지지는 않지만 **스스로 서지도 못한다.**
> 한 번 각속도를 얻으면 그대로 계속 돈다.
> 수학적으로는 적분기 두 개(`δ → θ̇ → θ`)뿐인 시스템이다.

이것이 "능동 제어로만 서는 기체"의 정확한 의미다.

## 1-6. 병진 — 위치는 자세에 종속된다

```
수평:   m·ẍ = T·sin(θ + δ)  ≈  T·(θ + δ)
수직:   m·z̈ = T·cos(θ + δ) − m·g  ≈  T − m·g
```

호버 상태(`T ≈ mg`)에서 수평 가속도는

```
ẍ ≈ g · θ        ... (3)
```

**기울이지 않으면 움직일 수 없다.** 위치를 제어하려면 자세를 먼저 제어해야 한다.
목표를 호버링 → 위치제어 2단계로 나눈 근거가 이 식이다.

## 1-7. 비최소위상 — 처음엔 반대로 간다

오른쪽으로 이동하려면:

```
① 기체를 오른쪽으로 기울여야 한다
② 기울이려면 짐벌로 아랫부분을 왼쪽으로 밀어야 한다
③ 그 순간 추력은 왼쪽 성분을 갖는다
④ 따라서 처음에는 왼쪽으로 가속된다
⑤ 기체가 기울어진 뒤에야 오른쪽으로 간다
```

가려는 방향과 반대로 먼저 움직인다. 제어공학에서 **비최소위상**이라 부르는 성질이다.

> **위치 루프를 빠르게 만들려 하면 반드시 불안정해진다.**
> 위치 루프가 자세 루프보다 훨씬 느려야 하는 이유가 이것이다.
> 위치 제어가 발산하면 먼저 이 문제를 의심할 것.

## 1-8. 지상 시험대는 자유비행보다 어렵다

짐벌 스탠드에 고정하면 회전축이 무게중심 **아래**에 생기고, 중력이 모멘트를 만든다.

```
I_pivot · θ̈ = T·L·sin δ  +  m·g·d·sin θ
                             ↑ d = 회전축 ~ 무게중심 거리
```

`+m·g·d·θ` 는 부호가 **양수**다. 기울어질수록 더 기울어지게 미는 항, 곧 역진자다.
자유비행보다 불안정하다.

> 시험대에서 자세가 잡히면 실제 비행에서는 더 쉽다.
> 안전하면서 더 엄격한 조건이므로 초기 검증에 적합하다.

# 2부. 제어 구조

## 2-1. P 제어만으로는 안 되는 이유

식 (2)에 `δ = −Kp·θ` 를 대입한다.

```
θ̈ + (T·L·Kp / I)·θ = 0
```

`θ̈ = −ω²θ` 꼴이다. 해는 `sin(ωt)`, `cos(ωt)` — **영원히 진동한다.** 감쇠가 없다.

감쇠를 만들려면 속도에 비례하는 항이 필요하다.

```
δ = −Kp·θ − Kd·θ̇

θ̈ + (T·L·Kd/I)·θ̇ + (T·L·Kp/I)·θ = 0
        ↑ 댐퍼               ↑ 스프링
```

재료역학·진동의 **질량–스프링–댐퍼**와 같은 식이다.
`Kp`가 스프링 상수, `Kd`가 감쇠 계수 역할을 한다.

> `Kd·θ̇` 항이 곧 "각속도 피드백"이고, 이것이 캐스케이드의 안쪽 루프가 된다.
> **캐스케이드는 임의로 만든 구조가 아니라 이 식에서 필연적으로 나온다.**

## 2-2. 캐스케이드 구조

```
위치목표 →[위치 루프]→ 자세각목표 →[자세각 루프]→ 각속도목표 →[각속도 루프]→ 짐벌각 → 기체
            느림                        중간                        빠름
```

| 루프 | 오차 입력 | 출력 | 측정 수단 | 제어기 | 교차주파수 |
|---|---|---|---|---|---|
| **각속도** | 각속도 오차 | 짐벌각 `δ` | 자이로 (직접) | P 또는 PI | 4~8 Hz |
| **자세각** | 각도 오차 | 목표 각속도 | 자이로+가속도 융합 | P | 1~2 Hz |
| **위치** | 위치 오차 | 목표 자세각 | GPS/광류/거리센서 | PD | 0.2~0.5 Hz |

각 루프 사이를 **4~5배씩 벌린다**(시간 척도 분리).
안쪽이 충분히 빠르면 바깥 루프 설계 시 "안쪽은 목표를 즉시 따라간다"고 근사할 수 있고,
그래야 세 루프를 한꺼번에가 아니라 **하나씩** 설계할 수 있다.

자세각 루프가 P만으로 충분한 이유: 각도와 각속도는 적분 관계이므로,
안쪽 각속도 루프가 이미 미분항 역할을 한다.

## 2-3. PID 각 항의 의미

| 항 | 무엇을 보는가 | 물리적 대응 |
|---|---|---|
| **P** | 지금 얼마나 틀어져 있나 | 스프링 |
| **D** | 얼마나 빨리 틀어지고 있나 | 댐퍼 |
| **I** | 계속 한쪽으로 틀어져 있나 | 정상편차 제거 |

**TVC에서 `I`가 반드시 필요한 이유**: 실제 기체는 무게중심이 기하학적 축에서 어긋나 있고,
추력축 정렬 오차와 프로펠러 반토크도 있다.
그래서 똑바로 서 있으려면 **짐벌을 항상 조금 꺾고 있어야 한다.**
`P`는 오차가 0이면 출력도 0이라 그 상수 오프셋을 만들 수 없다. `I`가 누적으로 그 값을 찾아낸다.

## 2-4. 대역폭 상한은 제어기가 아니라 구동기가 정한다

순수 시간지연 `τ`는 주파수 `ω`에서 `ω·τ` [rad]만큼 위상을 늦춘다.
위상여유 확보를 위해 교차주파수에서 30°(0.52 rad) 안쪽으로 묶으면

```
ω_c ≤ 0.52 / τ
```

서보 지연 20 ms 기준

```
ω_c ≤ 0.52 / 0.02 = 26 rad/s ≈ 4 Hz
```

> **이 계산이 서보 선정 기준이 된다.**
> 자세 응답을 더 빠르게 하려면 게인을 올리는 것이 아니라 더 빠른 서보를 써야 한다.
> 게인만 올리면 진동하다 발산한다.

제어 주기 250 Hz는 나이퀴스트가 125 Hz지만 실제 사용 가능 대역폭은 그 1/10~1/20인 12~25 Hz다.
위 4~8 Hz는 이 안에 들어오므로 250 Hz면 충분하다 — MCU 선정 근거.

## 2-5. 설계 순서 — 안쪽부터 하나씩

```
① 각속도 루프를 닫는다  → 스텝 응답 확인 → 통과하면
② 자세각 루프를 닫는다  → 스텝 응답 확인 → 통과하면
③ 위치 루프를 닫는다
```

각 단계에서 Simulink Control Design으로 그 시점의 모델을 선형화하고 PID Tuner를 돌린다.
세 루프를 동시에 튜닝하면 무엇 때문에 불안정한지 알 수 없다.

## 2-6. 시뮬레이션에 반드시 넣어야 할 비이상성

이상적인 구동기로 시뮬하면 실기에서 반드시 발산한다.

- 서보 각속도 제한 `δ̇_max`
- 서보 지연 `τ_servo`
- 짐벌 각도 포화 `δ_max`
- 제어 루프 이산화 주기 `f_ctrl`
- IMU 노이즈·바이어스 (Navigation Toolbox `imuSensor`)

파라미터 값은 [requirements.md](requirements.md) 3절 참고.
