# 요구사항 및 설계 목표

> **2026-09-09 기준 시작점 값입니다.** 확정값이 아닙니다.
> 시뮬레이션 결과와 CAD 실측으로 갱신하며, 변경 시 이 문서를 먼저 고칩니다.

## 1. 프로젝트 목표

프로펠러 추력의 방향을 짐벌로 꺾어(TVC) 로켓형 동체의 자세를 능동 제어한다.

1. **호버링** — 기체를 세운 자세로 공중에 유지
2. **위치 제어** — 원하는 지점으로 이동하고 그 자리를 유지

## 2. 기체 사양

| 항목 | 시작점 값 | 근거 | 확정 |
|---|---|---|---|
| 전장 `L_body` | 600 mm | 관성모멘트 확보와 취급성의 절충 | ☐ |
| 직경 | 90 mm | 배터리·전자부 수납 가능한 최소 수준 | ☐ |
| 이륙 중량 `m` | 800 g | 9~10인치 프로펠러로 T/W 1.8 확보 가능 | ☐ |
| 추력 `T` | 14 N | T/W = 1.8 (호버 필요추력 7.85 N) | ☐ |
| 추력 대 중량비 | 1.8 | 1.5 이상 필요, 여유 포함 | ☐ |
| **모멘트 팔 `L`** | 250 mm | 짐벌 회전중심 ~ 무게중심 거리 | ☐ |
| 짐벌 가동 범위 | ±12° (2축) | 제어 권한과 기구 간섭의 절충 | ☐ |
| 목표 비행 시간 | 60 초 | 초기 시험 기준. 이후 상향 | ☐ |

> `L`(모멘트 팔)이 제어 성능을 좌우하는 가장 중요한 값입니다.
> 제어 모멘트가 `M = T · L · sin δ` 로 결정되기 때문입니다.
> 자세한 유도는 [dynamics-and-control.md](dynamics-and-control.md) 참고.

## 3. 시뮬레이션 파라미터

2절 값에서 유도한, 모델에 직접 들어가는 값입니다.

| 기호 | 값 | 산출 근거 |
|---|---|---|
| `m` | 0.8 kg | 2절 |
| `I` | 0.024 kg·m² | 세장형 막대 근사 `I = (1/12)·m·L_body²` — **CAD 완성 후 실측값으로 교체** |
| `L` | 0.25 m | 2절 |
| `T` | 14 N | 2절 |
| `g` | 9.81 m/s² | |
| `δ_max` | 12° | 2절 |
| `δ̇_max` | 600 deg/s | 서보 사양 `0.10 s/60°` 환산 — **서보 확정 후 갱신** |
| `τ_servo` | 20 ms | 지령~반응 지연 추정 — **실측 후 갱신** |
| `f_ctrl` | 250 Hz | 4절 |

### 검산

```
최대 제어 모멘트   M_max = T·L·sin(δ_max) = 14 × 0.25 × 0.208 ≈ 0.73 N·m
최대 각가속도     θ̈_max = M_max / I      = 0.73 / 0.024      ≈ 30 rad/s² (≈1700 deg/s²)
```

제어 권한은 충분하다.

## 4. 제어 요구사항

| 항목 | 목표값 |
|---|---|
| 제어 루프 주기 | 250 Hz |
| 자세 추정 | IMU (자이로+가속도) 상보/칼만 필터 |
| 제어기 구조 | 위치 → 자세각 → 각속도 캐스케이드 |
| 정지 호버 자세 오차 | ±2° 이내 |

### 루프별 목표 대역폭

| 루프 | 교차주파수 | 제어기 | 비고 |
|---|---|---|---|
| 각속도 (안쪽) | 4~8 Hz | P 또는 PI | **서보 지연이 상한을 결정** |
| 자세각 | 1~2 Hz | P | |
| 위치 (바깥) | 0.2~0.5 Hz | PD | 비최소위상 때문에 느려야 함 |

각 루프 사이를 4~5배 벌려 시간 척도를 분리한다.

> 서보 지연 20 ms 기준 상한: `ω_c ≤ 0.52/τ = 26 rad/s ≈ 4 Hz`
> **더 빠른 자세 응답이 필요하면 게인이 아니라 서보를 바꿔야 한다.**

## 5. 하드웨어 후보

| 구성 | 후보 | 비고 |
|---|---|---|
| MCU | STM32F4·G4 / Teensy 4.x / 자체 설계 보드 | 250 Hz 루프에는 여유 있음. Simulink 코드생성은 STM32가 유리 |
| IMU | MPU6050(보유) → ICM-42688·BMI270 등 검토 | 보유 부품으로 우선 검증 |
| 짐벌 구동 | 서보 2축 | **각속도·지연 사양이 대역폭을 결정** |
| 추력원 | BLDC + ESC + 9~10인치 프로펠러 | 추력 14 N 확보 필요 |
| 텔레메트리 | RadioHead 계열 RF(보유) / ESP32 Wi-Fi | 보유 라이브러리 활용 가능 |
| 전원 | LiPo + BEC | 비행시간 60초 기준 용량 산정 |

> 지상 시험대는 회전축이 무게중심 아래에 있어 **자유비행보다 불안정**하다.
> 안전하면서 더 엄격한 조건이므로 초기 검증에 적합하다.
