## 1. 프로젝트 목표

프로펠러 추력의 방향을 짐벌로 꺾어(TVC) 로켓형 동체의 자세를 능동 제어하고,
수직 상승 → 호버링 → 안정 착륙까지 수행한다.

## 4. 하드웨어 후보

| 구성 | 후보 | 비고 |
|---|---|---|
| MCU | Teensy 4.x / STM32F4·G4 / 자체 설계 보드 | 고속 루프 여유 필요 |
| IMU | MPU6050(보유) → BMI270·ICM-42688 등 검토 | 보유 부품으로 우선 검증 |
| 짐벌 구동 | 서보 2축 | 응답속도·백래시 확인 필요 |
| 추력원 | BLDC + ESC + 프로펠러 | |
| 텔레메트리 | RadioHead 계열 RF(보유) / ESP32 Wi-Fi | 보유 라이브러리 활용 가능 |
| 전원 | LiPo + BEC | |
